# Componentes de terceros

`ui/globe.tsx` procede de la biblioteca de componentes **Originkit** y se instaló
con su CLI. Se conserva aquí, dentro del proyecto, como el propio instalador
indica; su autoría y sus condiciones de uso son las de Originkit, no las de este
portafolio.

El resto del código de `web/src` es obra de Nestor Elihu Arriaga Gallegos.
